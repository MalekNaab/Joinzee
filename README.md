# Joinziie

Find. Match. Join.

Joinziie is a platform that helps parents and young people discover,
match with and join activities, clubs and opportunities near them.

## Project Structure

mobile/
React Native + Expo application for parents and young people.

portal/
React web application for organisations and Joinziie administrators.

server/
Node.js + Express REST API.

docs/
Architecture and technical documentation.

## Planned Stack

## MVP

Parent / Guardian:
- Registration
- Child profiles
- Interests
- Discover activities
- Swipe and save
- Book activities
- My Activities

Young Person:
- Registration
- Interests
- Discover
- Save
- Book eligible activities

Organisation:
- Registration
- Verification
- Create activities
- Manage bookings
- View remaining spaces

Admin:
- Review organisations
- Approve or reject verification
